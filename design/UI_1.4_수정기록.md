# UI 1.4 수정 기록

2026-09-06. 기존 기획서의 한국어 글쓰기, 실제 본문 관찰, 교사 중심 WebRTC 연결 원칙을 따라 사용자가 요청한 9개 항목을 반영했다.

## 변경

1. 관찰·직접 수정 알림을 원고의 ‘나의 이야기’ 자리에 표시한다. 알림 등장으로 본문이 밀리지 않는다. 기존 교사 설정을 따른다.
2. 기본 줄간격을 160%로 줄이고 문단 아래의 추가 여백을 없앴다. 자동 줄바꿈과 Enter 문단에 같은 줄간격을 적용한다.
3. 줄간격을 60~300%, 10% 단위로 선택한다. 선택 서식은 Yjs 문서와 게시본에 반영한다.
4. 교사 전체 글·나란히 읽기에서 같은 본문 렌더러를 사용한다. 빈 문단을 제거하지 않고 읽기 화면에서도 높이를 유지한다.
5. 게시판 카드는 문단을 문자열 하나로 합치지 않고 원본 HTML의 문단·빈 줄·줄바꿈·서식을 보여 준다. 읽기 창과 HTML 내보내기에도 적용한다.
6. 카드별 펼치기·접기로 상세 창 없이 글과 출처를 끝까지 읽는다.
7. 그룹 설정에 ‘게시글 자동으로 펼치기’를 추가했다. 교사 설정은 모든 학생에게 전달되고 수업과 함께 저장된다. 기본은 접힘이다.
8. 게시 버튼을 ‘게시하기 / 수정한 글 게시하기’로 바꾸고, 교사 측 처리 완료 응답을 받은 뒤 게시판으로 이동한다. 실패 시 원고 화면에 남는다.
9. 글쓰기 하단에 ‘선생님께 도움 요청’과 ‘메시지 보내기’를 제공한다. 도움 요청·취소는 처리 응답 후 창을 닫으며 실패 시 내용을 유지한다. 메시지에는 원고별 대화 기록, 교사의 답장, 읽음 상태, 새 답장 배지를 제공한다. 교사는 전체 글의 ‘새 메시지’ 필터와 원고 카드 배지에서 찾는다.

## 통신과 보관

`src/classroom.ts`의 교사 측 요청 처리에 메시지 전송·읽음 처리를 연결했다. 원고 소유자와 실제 연결 상대를 확인하며 발신자·시각·ID는 교사 측에서 결정한다. 참가자별 비공개 데이터에 대화를 저장하고 해당 학생에게만 보낸다. 그룹 자동 펼치기는 기존 그룹 저장·배포 경로를 사용한다. 중앙 Node 서버는 기존처럼 페이지·입장·연결 신호를 제공한다.

교사와 학생의 IndexedDB에 대화와 설정을 보관한다. 공개된 원고에는 개인 대화를 넣지 않는다. 교사용 결과 파일에는 현재 원고에 관한 대화를 포함한다.

## 확인

- `npm run build`: TypeScript 및 배포 빌드 성공. 기존 단일 JS 묶음 크기 안내는 남아 있다.
- 기존 교사 1명·학생 2명 검사에 이번 변경의 회귀 확인을 추가했다. localhost 프로젝트 1개 통과(24.7초), 일반 HTTP 호스트 프로젝트 1개 통과(20.9초).
- 60% 서식의 실제 계산된 줄간격과 교사 문서 동기화, 빈 문단 2개의 높이, 문단 여백 제거, 관찰 상태 전후 본문 위치 유지 확인.
- 도움 요청과 교사 확인, 학생 질문·교사 답장·읽음·새 답장 배지, 게시 후 이동, 카드 펼치기, 그룹 자동 펼치기 전파와 재입장 후 복원 확인.
- 학생·교사 새로고침, 오프라인 본문 병합, 기존 피드백·댓글·수업 종료·HTML 내보내기·지난 수업 재개 흐름 통과.
- 다른 학생의 저장 데이터와 중앙 WebSocket 프레임에 비공개 질문·답장이 포함되지 않음을 확인.
- 390px 학생 화면에서 가로 넘침 없음과 하단 버튼 배치를 확인하고 스크린샷을 살펴봤다.

같은 Windows PC의 독립 Chrome 컨텍스트에서 검증했다. 일반 HTTP 호스트도 로컬 PC로 연결한 환경이다. 실제 Android 화면 키보드·한글 조합, 학교망, N100 성능을 검증한 것은 아니다.
