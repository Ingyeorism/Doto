# 도토 UI 시안

따뜻한 아이보리·초록·갈색을 사용한 교실 글쓰기 UI입니다. `Doto_기획서.md` 1.3을 반영했습니다. 프로그램 사용이 서툰 초등학생은 태블릿 화면 키보드, 교사는 컴퓨터를 사용하는 수업을 기준으로 합니다.

현재는 **단일 탭에서 화면과 조작을 살펴보는 프로토타입**입니다. 실제 수업 생성·학생 연결·다른 기기 전송·인증은 아직 없습니다. 게시판 제목·그룹·원고·게시본·피드백·댓글·휴지통은 이 브라우저에 저장되어 새로고침 후에도 유지됩니다. 브라우저 데이터를 지우면 함께 지워지며, 여러 탭에서 같은 게시판을 동시에 편집하는 동기화는 지원하지 않습니다. 수업 시작·설정 화면의 예시 값은 이 보관 범위에 포함하지 않습니다.

## 열기와 화면 경로

**`도토 UI 열기.cmd`**를 더블클릭하면 교사 전체 글 화면을 엽니다. Node.js가 필요하고, 패키지가 없으면 첫 실행에 설치합니다.

| 화면         | 주소                                             | 내용                                      |
| ------------ | ------------------------------------------------ | ----------------------------------------- |
| 교사 시작    | http://127.0.0.1:5173/teacher/start              | 수업 시작·지난 수업                       |
| 교사 전체 글 | http://127.0.0.1:5173/teacher/overview           | 원고 카드·그룹 필터·직접 수정·구절 피드백 |
| 교사 게시판  | http://127.0.0.1:5173/teacher/board              | 주제 그룹·정렬·드래그 이동·댓글           |
| 학생 입장    | http://127.0.0.1:5173/student/join               | 코드와 이름 입력 후 게시판                |
| 학생 게시판  | http://127.0.0.1:5173/student/board              | 친구 글과 자기 원고·그룹별 +              |
| 글쓰기       | `/student/write/:docId`, `/teacher/write/:docId` | 선택한 그룹의 자기 원고                   |

예전 `#/teacher`, `#/write` 등의 주소도 새 경로로 전환합니다. 학생 화면에는 교사 메뉴나 ‘글쓰기’ 탭, 학생 홈을 두지 않습니다. 교사는 게시판의 +로 교사 명의의 안내 글도 쓸 수 있습니다.

교사 화면 아래 **‘학생 화면 보기’**로 이동하면 같은 탭에서 김하늘 학생의 화면을 볼 수 있습니다. 교사 화면으로 돌아갈 때는 브라우저 뒤로 가기를 사용합니다. 별도 탭·기기는 서로 연결되지 않으며 URL 분리 자체가 접근 권한 인증은 아닙니다.

## 주제별 게시판

예시 그룹은 ‘마음에 남은 하루’, ‘내가 발견한 작은 것’, ‘처음 해 본 일’입니다. 실제 새 수업의 기본값은 기획서대로 그룹 하나이며, 현재 시안은 여러 그룹을 보여 주는 예시 수업입니다.

- 그룹의 +를 누를 때마다 새 원고를 만듭니다. 게시판으로 돌아가면 자기 미게시 원고는 비공개 카드로 남습니다.
- ‘게시하기’는 그 시점의 제목·본문만 해당 그룹에 공개합니다. 개인 피드백은 제외합니다.
- 게시한 글을 고친 후 ‘고친 글 올리기’를 누르면 기존 게시글과 댓글을 유지합니다. 새 글을 올리는 버튼은 ‘친구들에게 올리기’입니다.
- 교사는 게시판 제목 옆 연필로 제목을 수정하고 저장·취소합니다. 고정 소개 문구는 제거했습니다.
- 교사는 그룹을 추가·수정하고 손잡이 드래그로 순서를 바꿉니다. 좌우 이동 화살표는 제거했습니다.
- 글 손잡이를 다른 그룹으로 드래그하거나 ‘그룹 이동’ 메뉴로 옮깁니다. 미게시 원고는 교사 전체 글의 상세 패널에서 옮깁니다.
- 정렬은 새 글 아래·최신 글 위·이름순·제목순·직접 배치입니다. 같은 그룹 안의 글 드래그 정렬은 직접 배치에서 사용합니다. 자동 정렬 중에도 그룹 간 이동은 가능합니다.
- 글이 있는 그룹과 마지막 그룹도 삭제 확인 후 삭제할 수 있습니다. 원고와 게시글 수를 보여 주며, 취소하면 유지합니다.
- 삭제한 그룹·원고·게시본·피드백·댓글은 교사용 **휴지통에 30일간** 보관합니다. 그룹 전체 또는 글 하나씩 복원할 수 있습니다. 원래 그룹이 없으면 함께 복원합니다. 만료된 항목은 다음 불러오기나 주기적 정리 때 제거합니다.
- 그룹 이동과 휴지통 복원은 작성자·댓글·피드백·문서 ID를 유지합니다. 게시글의 ‘게시 내리기’는 공개만 취소하고 개인 원고를 남기는 별도 동작입니다.

[패들릿 공식 섹션 안내](https://padlet.help/l/en/article/4hhcm0aujp-secciones)와 [게시글 정렬 안내](https://padlet.help/l/en/article/l4wafxzlcm-sortera-block)를 참고해 구성했습니다.

## 구절 피드백

교사 전체 글 상세에서 본문 일부를 드래그하면 **‘피드백 하기’** 메뉴가 나타납니다. 게시판의 큰 글 보기에서도 **‘원고에 피드백’**을 눌러 현재 원고에 남길 수 있습니다. 공개된 과거 게시본과 현재 원고를 구분합니다.

노란 표시 위에 마우스를 올리거나 터치 화면에서 약 0.5초 누르면 메시지 팝업이 열리도록 구현했습니다. 클릭·짧은 터치·키보드 Enter/Space도 지원합니다. 움직이거나 스크롤하면 길게 누르기를 취소합니다.

| 글을 고치면                      | 표시와 메시지                                                          |
| -------------------------------- | ---------------------------------------------------------------------- |
| 표시 바로 앞뒤에 이어 씀         | 새 글은 하이라이트에 포함하지 않음                                     |
| 표시 안쪽에 추가·부분 수정       | 범위가 내부 수정을 따라감                                              |
| 일부를 지움                      | 남은 범위로 줄어듦                                                     |
| 전부 지우거나 다른 문장으로 바꿈 | 표시만 사라지고 원래 인용문과 메시지는 ‘원래 문장이 바뀌었어요’로 유지 |
| 실행 취소·다시 실행              | 현재 에디터의 보관된 편집 이력에 맞춰 범위 복원·삭제                   |
| 서식 지우기·복사·공개            | 서식 지우기는 피드백에 영향 없음. 복사·공개에는 피드백 제외            |

동일한 문장을 다시 썼다는 이유만으로 피드백을 자동 연결하지 않습니다. 현재 범위 추적은 ProseMirror 위치 매핑과 별도의 Decoration을 사용하고, 실제 협업 연결 때는 Yjs 상대 위치로 연결해야 합니다. 에디터를 닫으면 실행 취소용 이력은 초기화되지만 이 탭의 원고·피드백 상태는 유지됩니다.

## 초등학생을 위한 수업 도움 — UI 1.3

교사 **전체 글**에는 참여 학생 명단과 원고 수가 따로 표시됩니다. 원고 없음·초안·게시됨·도움 요청·고친 글 확인 필터를 사용할 수 있습니다. 참가자는 원고를 삭제해도 명단에 남으며, 현재 인원은 UI 시안의 참가자 데이터입니다.

학생은 게시판이나 글쓰기 하단에서 **도움 요청**을 누릅니다. 설명은 안 적어도 됩니다. 글의 그룹을 잘못 골랐다면 도움 종류에서 ‘다른 그룹으로 옮겨 주세요’를 고릅니다. 교사는 전체 글에서 요청을 확인하고 원고와 게시본을 함께 옮깁니다.

글쓰기 하단에는 **실제 저장 상태와 공개 상태**가 따로 표시됩니다. 고쳤지만 아직 올리지 않은 글은 ‘게시판에는 고치기 전 글이 보여요’로 안내합니다. 하단 동작 막대는 화면 키보드가 줄인 표시 영역을 따라 배치하도록 구현했으며, 실제 Android 키보드 검증은 아직입니다.

교사 **게시판 → 그룹 설정 → 수업 자료·글쓰기 도움**에서 필요한 것만 준비합니다.

- 생각 질문 최대 3개: 빈칸은 숨깁니다. 서평·조사 질문 예시를 넣고 자유롭게 고칠 수 있습니다. 학생의 답안을 자동으로 넣지 않습니다.
- 자료 최대 2개: 주소 또는 그림만 넣어도 됩니다. 이름을 생략하면 ‘선생님 자료’입니다. 교사의 PNG·JPG·WebP 그림은 자동으로 크기를 줄여 보관합니다.
- 출처 칸 표시: 기본은 꺼짐이고 조사 질문 예시를 넣으면 켜집니다. 학생은 기관·자료명·날짜·주소 중 아는 것만 적습니다. 모두 비워도 게시할 수 있습니다. 적은 출처는 공개할 때 함께 올라갑니다.

학생 게시판에는 자료 링크가 바로 보이고, 작성 중에는 **수업 도움 보기**에서 안내·자료·생각 질문을 펼칩니다. 출처는 본문 아래 **출처 남기기**에 있습니다. 기존에 적은 출처는 교사가 표시 옵션을 꺼도 지워지지 않습니다.

피드백의 **읽었어요 / 고쳤어요**는 학생의 확인 표시입니다. 교사는 고친 글을 읽고 **확인 완료 / 다시 살펴봐요**를 선택합니다. 자동 채점이나 자동 해결이 아니며, 인용문과 메시지는 계속 남습니다.

[선택한 11개 피드백의 적용 판단과 확인 기록](UI_1.3_피드백_적용기록.md)에 상세 내용을 남겼습니다. 새 정보도 기존 게시판과 함께 같은 브라우저에 저장합니다.

## 글쓰기 도구와 개발

Tiptap의 한국어 도구막대에 글꼴·글자 크기·굵게·기울임·밑줄·색·정렬·실행 취소·다시 실행을 제공합니다. ‘더 보기’에는 줄간격·들여쓰기·목록·서식 지우기가 있습니다. 수업 초대·설정·종료·지난 수업은 기존 화면 시안이며 QR은 스캔용 코드가 아닙니다.

React + TypeScript + Vite, Tiptap, Lucide 아이콘을 사용합니다. 웹폰트가 없으면 시스템 글꼴로 표시합니다.

```sh
npm install
npm run dev
```

`npm run dev`는 현재 터미널에서 실행되며 `Ctrl+C`로 종료합니다. 배포용 빌드는 `npm run build`입니다.

주요 파일은 `src/App.tsx`(경로·상태), `src/Community.tsx`(그룹 게시판), `src/board-state.ts`·`src/TrashPanel.tsx`(보관·복원), `src/Teacher.tsx`(교사 상세), `src/Student.tsx`(원고), `src/WritingEditor.tsx`(선택·편집), `src/feedback-extension.ts`(범위 추적), `src/FeedbackSurface.tsx`(팝업·피드백 목록)입니다.

UI 1.1에서는 요청에 따라 검사를 미뤘고, **UI 1.2에서 빌드·타입 검사, 휴지통 데이터 검사 4개와 핵심 브라우저 흐름을 확인했습니다.** 그룹·게시글 드래그와 구절 전체 교체에서 발견한 문제를 고쳤습니다. 검사 기록은 `design/UI_1.2_구현기록.md`에 있습니다. 실제 Android 길게 누르기·한글 조합·화면 키보드와 실제 서버·WebRTC·Yjs 협업·IndexedDB 보관은 후속 개발·확인 범위입니다.

휴지통의 짧은 데이터 검사는 Node.js 22 이상에서 다음과 같이 실행합니다.

```sh
node --experimental-strip-types scripts/smoke-trash.mjs
```

UI 1.3의 공개본 비교·선택 입력·참가자와 관련 정보 보존 검사는 다음과 같습니다. 검사 결과와 브라우저 확인 범위는 위 1.3 기록에 정리했습니다.

```sh
node --experimental-strip-types scripts/smoke-learning.mjs
```

가상 교사·학생 발언은 AI가 구성한 사용성 가설이며 실제 인터뷰 결과가 아닙니다. 각 수업은 초등 5~6학년 기준 40분×2차시이고, 입력이 느린 학생에게 짧은 초안·말하기·종이 메모를 허용합니다.
