# 태블릿 서버 UI 시안

2026-09-08. 기존 도토 접속 주소와 코드 입장 방식을 유지하면서, 수업 호스트를 태블릿으로 옮기는 화면 제안이다. 실제 통신 구조 변경에 앞서 화면을 검토하는 용도다.

이후 승인한 화면을 실제 수업에 연결했다. 실제 구현과 검증은 [태블릿 서버 실제 연결](태블릿_서버_실제연결.md)을 참고한다. 아래 내용은 `?preview=tablet` 시안의 동작 기록이며, 실제 실행은 `도토 열기.cmd`를 사용한다.

## 열기

프로젝트의 `도토 태블릿 시안 열기.cmd`를 실행한다. 개발 서버가 열려 있으면 `http://127.0.0.1:5173/teacher/start?preview=tablet`로 접속할 수 있다.

하단 UI 시안 바에서 시작, 서버 태블릿, 방 입장, 교사 PC으로 이동할 수 있다. 통합 입장창에서는 **교사 코드 예시 / 학생 코드 예시**로 두 입장 흐름을 확인할 수 있다.

## 확인할 흐름

1. 메인은 왼쪽 **수업 열기**, 오른쪽 **방 입장하기** 두 카드로 구성한다. 카드 번호는 없으며 제목은 원래의 “작은 생각이 이야기로 자라는 곳.”을 사용한다.
2. 수업 열기 → 수업 이름 입력 → 방 열고 코드 받기. 첫 카드의 설명은 “학생 와이파이에 연결된 기기로 수업을 시작해요.”다.
3. 서버 관리 화면 왼쪽에 교사용 코드, 오른쪽에 학생용 코드를 바로 표시한다. 안내는 “교사용 컴퓨터에서 이 코드를 입력해 주세요.”와 “학생들에겐 이 코드를 안내해주세요.”이며, 각 문장 앞에 1·2 원형 배지를 표시한다.
4. 방 입장 카드는 `/join?preview=tablet`로 이동한다. 교사용 코드면 바로 교사 화면, 학생용 코드면 이름을 입력한 뒤 학생 화면으로 들어간다. 기존 `/teacher/join`, `/student/join` 주소도 같은 통합 폼을 표시한다.
5. 서버 태블릿은 **전체 글 · 게시판 · 서버 관리** 탭을 쓴다. `/host/overview`와 `/host/board`에서 PC와 같은 교사 화면으로 글 수정·피드백·그룹·게시판·댓글 관리가 가능하다.
6. 교사 화면은 `PreviewApp` 하나를 재사용한다. 서버 태블릿에는 서버 관리 탭과 **수업 마치기**, 접속한 PC에는 **PC 연결 나가기**를 제공한다. PC 접속 여부와 관계없이 서버 태블릿의 교사 기능을 사용할 수 있다.
7. 서버 관리 → 어둡게 켜 두기 → 밝은 화면으로 복귀. Esc로도 복귀한다.
8. 연결 관리에서 신규 입장 잠금, 교사용 코드 재발급을 확인한다. 재발급하면 이전 교사 코드는 무효가 되고 교사 PC 연결이 해제된다.
9. **수업 마치기**는 PC 연결 나가기와 별개의 확인창을 거쳐 방을 종료한다.

## 시안 범위

- 교사 예시 코드: `7391 8426`. 재발급 예시 코드는 `8264 9317`과 번갈아 표시된다.
- 학생 예시 코드: `482 716`. QR은 이 로컬 시안의 학생 입장 페이지를 가리킨다. 다른 기기 접속을 검증하는 QR이 아니다.
- 방 상태는 `doto.tablet-host.ui.v1`, 예시 원고는 `doto.board.v2:tablet-preview`, 글감·교사 설정은 `doto.tablet-classroom.ui.v1`에 보관한다. 기존 수업 및 기존 UI 시안의 보관 키와 분리한다.
- 교사 PC의 원고는 기존 예시 학생 12명의 데이터다. 하단에 예시 데이터임을 표시한다.
- 학생은 입장 시 발급한 별도 ID로 자기 초안과 게시자를 구분한다. 기존 예시 김하늘(ID 0)을 로그인 학생으로 사용하지 않는다. 현재 탭의 입장 정보는 `doto.tablet-student.ui.v1` 세션 저장소에 보관하며 새로고침 시 복원한다. 이름만으로 다른 학생의 원고를 가져오지 않는다.
- 학생 화면과 학생 코드가 입력된 입장창에는 서버 연결 설명, 사용 안내의 서버 운영 설명, 시안용 교사·서버 화면 전환 메뉴를 표시하지 않는다. 글 저장 결과, 게시 여부, 개인 피드백·도움 요청은 유지한다.
- 실제 서버 시작, 기기 간 문서 동기화, 권한 인증, 배터리 측정, 화면 꺼짐 방지, 백업은 이번 변경에 포함하지 않는다. 교사 코드는 실제 인증 기능이 아닌 화면 흐름용 값이다.
- 기존 실제 수업 화면과 `?preview=1`의 진입 방식은 유지한다.

## 구현 파일

- `src/TabletHostPreview.tsx`: 역할별 입구, 방 생성, 서버 관리, 코드 입장, 연결·종료 대화상자.
- `src/tablet-host-preview.css`: PC·태블릿·작은 화면 대응 및 어두운 유지 화면.
- `src/PreviewApp.tsx`: 시안용 교사 연결 배너·나가기 동작을 선택적으로 받아 기존 편집 화면을 재사용.
- `src/main.tsx`: `?preview=tablet` 진입 분기.
- `scripts/open-ui.mjs`: `--tablet` 실행 옵션.

## 확인 결과

- `npm run build` 통과. 기존 단일 번들 크기 경고는 남아 있다.
- 인앱 브라우저에서 방 생성, 교사 코드 표시, 잘못된 코드 안내, 정상 교사 입장, PC 연결 나가기 후 방 유지, 어두운 화면 복귀, 신규 학생 입장 잠금·해제, 학생 게시판 입장, 수업 종료를 확인했다.
- 1440×900 PC 시작 화면, 1024×768 태블릿 가로, 768×1024 태블릿 세로, 390×844 작은 화면의 배치를 확인했다. 확인한 세로 태블릿·작은 화면에서 가로 넘침이 없었다.
- 확인 중 브라우저 오류 로그가 없었다. 실제 여러 기기 연결과 Android 화면 유지 기능을 검증한 것은 아니다.
- 후속 수정에서 통합 폼의 잘못된 코드 안내, 교사·학생 코드별 화면 선택, 교사 코드 입력 시 학생 이름 생략, 서버 태블릿의 직접 수정과 서버 관리 왕복 후 원고 유지, `/host/board` 새로고침을 확인했다. 390px 화면에서 교사용 카드가 먼저 나오고 가로 넘침이 없었다.
- 학생 ID 수정은 별도 5174 포트의 시안에서 확인했다. 이강우 입장 시 예시 김하늘의 초안이 없고, 이강우의 새 초안은 새로고침 후 복원됐으며 이강우 이름으로 게시됐다. 박서연으로 들어온 별도 탭에는 이강우의 미게시 초안이 없었다. 확인 후 검증용 서버와 탭을 종료했다.
