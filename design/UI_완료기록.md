# 도토 UI 시안 완료 기록

작성일: 2026-09-05

선택한 따뜻한 도토리 이미지 시안을 바탕으로 React + TypeScript + Vite 화면을 구성했다.

시작, 코드 입장, 교사 전체 보드, 게시판, 학생 홈, 글쓰기, 지난 수업의 7개 화면과 초대·설정·글감 수정·수업 종료·게시 완료 팝업을 만들었다. 교사 보드에는 학생 본문 12개, 우측 상세와 피드백, 카드 크기·정렬·나란히 읽기 UI를 구성했다.

본문 편집기는 Tiptap으로 구현했다. 글꼴·크기·굵게·기울임·밑줄·글자색·정렬·줄간격·들여쓰기·목록·되돌리기를 조작할 수 있다. 공개 글의 본문 표시에서는 교사 개인 피드백 표시를 제외한다. 게시와 댓글은 시안 내부의 일시적인 화면 변화다.

확인한 내용:

- TypeScript 검사와 프로덕션 빌드 통과.
- 실행 도우미 JavaScript 구문 검사 통과.
- 브라우저에서 7개 화면 전환과 게시글 상세·댓글 입력 표시 확인.
- 글자 크기 24px, 굵게, 명조, 가운데 정렬 적용 확인.
- 줄간격 220% 적용과 실행 취소 후 본문 유지 확인.
- 데스크톱 1440×1000, 태블릿 820×1180 및 좁은 미리보기 패널에서 배치 확인. 태블릿 글쓰기 화면에 가로 넘침이 없는 것을 확인.

실제 방 생성, 학생 연결, 메시지 전송, 문서 저장, QR 입장, HTML 결과 내보내기는 아직 구현하지 않았다. 실제 기기의 한글 조합 입력과 학교망 연결을 검증한 상태가 아니다. 이 기록은 첫 버전 전체의 개발 완료 보고가 아니라 UI 시안 작업의 완료 기록이다.
