# 교사 안내 1·2·3 제작 기록

2026-09-11. 실제 서비스 https://dotoschool.uk 의 PC 브라우저 화면을 먼저 캡처하고 이미지 생성 도구에 입력했다. 시안 모드나 로컬 개발 화면을 원본으로 사용하지 않았다. 학생용 태블릿을 쓰는 운영 절차를 설명하는 안내서이며, 실제 물리 태블릿에서 촬영했다는 뜻은 아니다.

## 01 학생용 태블릿 한 대로 수업 열기

- 최종 이미지: `01-student-tablet-open-final.png`
- 원본 캡처: `../manual-captures/2026-09-11/01-start.png`, `../manual-captures/2026-09-11/02-host-setup.png`
- 캡처 주소: `https://dotoschool.uk/`, `https://dotoschool.uk/host/setup`
- 예시 입력: `5학년 2반 글쓰기 · 안내서 예시`
- 운영 전제: 학생용 태블릿 중 한 대를 학생 와이파이에 연결하여 방을 연다. 충전기를 연결하고 수업이 끝날 때까지 도토 화면을 켜 둔다.
- 제작 방식: 내장 image_gen. 실제 캡처 2개를 입력하여 안내 레이아웃과 번호 화살표를 생성했다. 이후 주소 안내 문구를 추가했다.

## 02 교사 PC 연결하기

- 최종 이미지: `02-teacher-pc-connect-final.png`
- 실제로 발급된 교사용 코드 화면 → PC 입장 화면 → 연결된 교사 화면을 촬영했다.
- 원본 캡처: `09-host-pc-connected.png`, `04-teacher-code-entry.png`, `05-teacher-connected.png` (모두 `../manual-captures/2026-09-11/` 안)
- 실제 수업의 교사용 8자리 코드를 두 번째 브라우저 창에 입력하여 교사 화면 연결을 확인했다. 호스트 화면의 ‘PC 연결 1대’도 확인했다.
- 처음 사이트를 연 교사가 따라갈 수 있도록 ‘시작 화면에서 방 입장하기 선택’을 명시했다.
- 제작 방식: 내장 image_gen. 실제 캡처 3개와 1장 스타일 참조를 사용했다. 최종 안내 경로와 태블릿 아이콘을 보완했다.

## 03 글쓰기 주제 준비하기

- 최종 이미지: `03-writing-topic-prepare.png`
- 실제 교사 게시판의 그룹 만들기 → 주제·안내 입력 → 저장한 그룹을 촬영했다.
- 원본 캡처: `06-board-before.png`, `07-group-create-filled.png`, `08-board-group-created.png` (같은 캡처 폴더)
- 주제 예시: `추천하고 싶은 책`
- 글쓰기 안내 예시: `책 이름, 기억에 남는 장면, 추천하는 이유를 써요.`
- 원격 교사 창에서 그룹을 저장한 후 게시판에 실제로 나타난 상태를 확인했다.
- 제작 방식: 내장 image_gen. 실제 캡처 3개와 1장 스타일 참조를 사용했다.

## 촬영 완료

- 사용자가 촬영용 실행과 개인정보 동의를 명시적으로 승인했다.
- 2026-09-11, 필요한 장면 촬영 후 수업을 연 창에서 수업 마치기를 실행했다. 지난 수업의 ‘수업 종료’와 원격 교사 창의 ‘수업 종료’를 모두 확인했다.
- 촬영은 한 PC의 독립 브라우저 창에서 했다. 물리 태블릿·학교망 검증은 이번 안내 이미지 제작 범위에 포함하지 않는다.
- 실제 웹사이트 원본 캡처와 안내 이미지 생성에 사용한 영문 프롬프트를 함께 보관했다. AI로 편집한 안내 이미지에서는 글자·화면 배치 일부가 원본과 달라질 수 있으며 원본 PNG를 별도로 참고할 수 있다.

학생용 코드와 교사용 코드는 전달 대상이 다르다. 캡처 속 코드는 이미 종료한 촬영용 수업의 예시다.
